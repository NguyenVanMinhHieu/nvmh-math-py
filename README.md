# NVMH MATH-ARCH 📐✨

Hệ sinh thái phần mềm mã nguồn mở hỗ trợ nghiên cứu, giảng dạy và soạn thảo đề thi Toán THPT chuyên nghiệp bằng Python.

- **Động cơ CAS:** Phân tích giải tích biểu tượng toàn diện với SymPy.
- **Mô hình Hình học Song ánh (Geometric IR):** Ánh xạ đối xứng 1-1 chính xác từng milimet giữa LaTeX (TikZ + tkz-tab) và Typst (CeTZ 0.5.2).
- **Giao diện:** Web Studio Dark Mode hiện đại (FastAPI + MathJax 3) cùng công cụ dòng lệnh (CLI).


> 🌐 **Dùng thử trực tiếp trên Web (24/7):** [https://nvmh-math-py.onrender.com/](https://nvmh-math-py.onrender.com/)

## 🚀 Cài đặt nhanh qua uv

```bash
uv tool install git+https://github.com/NguyenVanMinhHieu/nvmh-math-py.git --force
```

## 📖 Hướng dẫn sử dụng

### 1. Khởi động Web Studio (Dark Mode)
```bash
nvmh-math-server
```

### 2. Dòng lệnh CLI
```bash
nvmh-math-py "(x^2 + 2*x - 3)/(x - 3)"
```
